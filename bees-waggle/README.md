# Bee's Waggle

The daily life of a bee as an animated radiograph, built with Three.js.

**[Launch the demo](https://thtbee.github.io/waggles/bees-waggle/)**

---

### Scenes

Specimen · Meadow · Nectar · The Hive · Swarm

### Film stocks

Radiograph · Cyanotype · Oxblood · Verdigris · Risograph · Ultraviolet · Phosphor P3

### Controls

| | |
| --- | --- |
| `1` – `7` | Film stock |
| `M` | Next film stock |
| `←` `→` | Previous / next scene |
| `S` | Auto-play |
| `A` | Glyphs |
| `P` | Freeze |
| `H` | Hide HUD |
| `F` | Fullscreen |

### Run locally

From the repo root, with Python 3:

```bash
python tools/serve.py
```

Then open [localhost:8000/bees-waggle](http://localhost:8000/bees-waggle/).
