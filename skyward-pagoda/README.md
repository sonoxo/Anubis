# Skyward Pagoda · 天空の塔

A floating voxel sanctuary, built with Three.js, TypeScript and Vite.

**[Launch the demo](https://thtbee.github.io/waggles/skyward-pagoda/)**

---

### Landmarks

Sanctuary Pagoda · Waterfall Cliff · Sakura Grove · Torii Path & Bridges · Mirror Lake · Hermit Peak · Root Caverns

### Times of day

Dawn · Day · Golden · Dusk · Night

### Controls

| | |
| --- | --- |
| `1` – `5` | Time of day |
| `Space` | Auto-cycle time |
| `P` | Wander mode |
| `W` | Weather |
| `Q` | Quality |
| `M` | Sound |
| `H` | Hide UI |
| `Esc` | Exit wander mode |

### Run locally

This folder holds the production build. From the repo root, with Python 3:

```bash
python tools/serve.py
```

Then open [localhost:8000/skyward-pagoda](http://localhost:8000/skyward-pagoda/).
