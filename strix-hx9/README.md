# STRIX HX-9

Real-time 3D concept gunship, built with Three.js.

**[Launch the demo](https://thtbee.github.io/waggles/strix-hx9/)**

---

### Environments

Borealis · Dune · Neon · Tempest · Eclipse · Stratos

### Controls

| | |
| --- | --- |
| `Space` | Launch / land |
| `1` – `4` | Camera: orbit, chase, cockpit, cinema |
| `T` | Next environment |
| `Q` `X` `P` `A` `E` | Skin, x-ray, power flow, airflow, exploded |
| `F` | Cannon (hold) |
| `R` `M` `C` | Rockets, missile, flares |
| `S` | Sound |
| `H` | Show controls |

Drag to orbit, scroll to zoom.

### Run locally

From the repo root, with Python 3:

```bash
python tools/serve.py
```

Then open [localhost:8000/strix-hx9](http://localhost:8000/strix-hx9/).
