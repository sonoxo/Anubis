# Kestrel K-1

A mechanically true humanoid robot, built with Three.js, TypeScript and Blender.

**[Launch the demo](https://thtbee.github.io/waggles/kestrel-k1/)**

---

### Views

Studio · Glass · Explode · Power · Signal · Section · Thermal · Drawing

### Liveries

Apex · Ember · Obsidian · Porcelain

### Controls

| | |
| --- | --- |
| `1` – `8` | View mode |
| `P` / `Shift` `P` | Next / previous pose |
| `W` | Walk |
| `I` | Inspect hand |
| `E` | Explode |
| `X` | X-ray style: glass or cutaway |
| `V` | Livery |
| `T` | Light / dark theme |
| `B` | Bill of materials |
| `C` | Cycle camera |
| `F` | Free-fly camera |
| `H` | Reset camera |
| `L` | Loupe |
| `Space` | Freeze |
| `M` | Sound |
| `/` or `Ctrl` `K` | Command line |

### Run locally

This folder holds the production build. From the repo root, with Python 3:

```bash
python tools/serve.py
```

Then open [localhost:8000/kestrel-k1](http://localhost:8000/kestrel-k1/).
